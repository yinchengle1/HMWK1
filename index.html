Elliptic Curve Cryptography

Private Key → Scalar Multiplication → Public Key

1. Define the Toy Curve

y² = x³ + 7 (mod 17)
Base point G = (1, 5)
Prime p = 17

The public key is Q = kG, where k is the private key.

4. Discussion

One-way property: Computing Q = kG is efficient, while recovering k from Q is the elliptic curve discrete logarithm problem on a suitably chosen large curve.

Deterministic: The same private key and base point always produce the same public key.

Not a hash function: Elliptic curve multiplication does not aim to provide a hash function's avalanche effect, collision-resistance properties, or uniform-looking output bit strings.

Important limitation: With p = 17, the group is tiny. Private keys repeat the same public points periodically, so this curve provides no real security.
